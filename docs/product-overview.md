# Coloralyzer — プロダクト概要

画像をアップロードするだけで、その画像に使われている色を **人間の知覚に沿った OKLCH 色空間** で解析・可視化する Web アプリです。明度・彩度・色相・色の広がり・配色比率を、数値とビジュアルの両面から把握できます。

---

## このアプリで何ができるか

6 つの分析ビューで、1 枚の画像の色彩を多角的に確認できます。

| ビュー | 何がわかるか |
|--------|-------------|
| **色彩の総合分析**（Overview） | 明度・彩度・色相の 3 軸でまとめて俯瞰。各指標のハイライトと統計値を一覧表示し、画像の色彩特徴を素早くつかめる。 |
| **彩度分析**（Chroma） | どこが鮮やかでどこが落ち着いた色かを彩度グレースケールで可視化。彩度ヒストグラムで「モノトーン寄りか／カラフルか」を判定。 |
| **明度分析**（Lightness） | どこが明るくどこが暗いかを明度グレースケールで可視化。ヒストグラムでローキー（暗い印象）／ハイキー（明るい印象）を判定。 |
| **色相分析**（Hue） | 色相環のどの範囲の色が多いかを 3D 地形チャートで立体表示。明度帯（Dark / Mid / Light）ごとの色相分布も切り替え可能。 |
| **3D ガマット**（Gamut） | 画像の全色を 3D 空間に点として配置し、配色の広がり・偏りを立体的に確認。ブラシで画像の一部をなぞると、その領域の色だけをハイライト。 |
| **色分布**（Distribution） | 似た色を自動でグループ化して代表色パレットを抽出。各色が占める面積比をバブルチャートと数値で表示し、配色バランスを把握。 |

### 主な操作・特徴

- **画像をアップロードするだけ** — 専門知識なしで全ビューを横断できる。
- **複数画像の比較** — ギャラリー付き分析エリアで、オリジナル画像と分析結果を並べて確認。
- **3D の自由な視点操作** — ガマット／色相地形はマウスドラッグで回転。ガマットには視点プリセット（真上・真下・初期）があり、タブを切り替えてもカメラアングルを保持して比較しやすい。
- **各機能に解説モーダル** — 「〜とは」「軸の読み方」など、色彩用語を知らなくても読み解けるガイド付き。
- **モバイル対応** — 画面が狭い環境では UI を最適化（説明文の自動省略、レイアウトのフォールバック等）。

## どんな人が、何のために使うのか

知覚的に正確な色の把握を必要とする、**ビジュアル制作・色設計に関わる人**に適しています。

- **イラストレーター / 絵描き** — 自作や参考画像の配色傾向を分析。「暗部は青、明部は黄」のような明度帯ごとの色相の使い分け、彩度の置き方を客観的に確認できる。真上ビューでの彩度・色相分布の比較が制作レビューに役立つ。
- **デザイナー / アートディレクター** — 画像の支配色・アクセント色を代表色パレットとして抽出し、配色バランスを数値で検証。
- **写真家 / レタッチャー** — 明度・彩度のヒストグラムでトーンの寄り（ローキー／ハイキー、モノトーン／カラフル）を確認し、現像・調整の指針にする。
- **色彩を学ぶ人 / 教育用途** — OKLCH の L・C・h を視覚的に体験しながら、明度・彩度・色相の概念を理解する教材として。

典型的な用途は、**「この画像の配色はなぜ良く見えるのか」を分解して言語化する**こと。感覚的な印象を、明度・彩度・色相・面積比という再現可能な指標に落とし込めます。

## 特徴：OKLCH による知覚的な色彩確認

本アプリの中核は、すべての解析を **OKLCH 色空間** で行う点にあります。

- **OKLCH とは** — 知覚的に均等な色空間。色を **L（明度）・C（彩度）・h（色相）** の 3 成分で表す。
  - **L / 明度**: 0（黒）〜 1（白）
  - **C / 彩度**: 0（無彩色）〜 約 0.4（最大彩度）
  - **h / 色相**: 0〜360 の角度（度数）
- **なぜ OKLCH なのか** — sRGB や HSL は「数値上の差」と「人間が感じる差」がずれる。OKLCH は知覚的に均等なため、たとえば「明度を一定に保ったまま彩度だけを比較する」「色味の違いを公平に並べる」といった分析が、人間の見た目どおりに行える。グレースケール変換・ヒストグラム・3D マッピングのいずれも、この知覚均一性の上に成り立っている。
- 画像の各ピクセルを sRGB から OKLCH に変換し（[Culori](https://culorijs.org/) を使用）、L・C・h を軸とした可視化に展開する。

- **アニメーション**: GSAP / Motion for Vue
